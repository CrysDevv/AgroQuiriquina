# AgroQuiriquina — Backend (Django + DRF)

API REST para la gestión de inventario, ventas, finanzas, contactos y RRHH de AgroQuiriquina,
pensada para una app móvil Android que trabaja **offline** y sincroniza al recuperar conexión.

- **Python** 3.10+ (recomendado 3.11 o 3.12) · **Django** 5.0/5.1 · **DRF** 3.15
- **Auth:** JWT (SimpleJWT) con RBAC por rol: `ADMIN`, `VENDEDOR`, `SUPERVISOR`
- **BD:** SQLite por defecto (prototipo) · PostgreSQL opcional
- **Herencia Multi-table:** `Persona → Cliente / Proveedor / Trabajador` e `ItemBodega → ProductoVenta / InsumoAgricola`

## 4. Aplicación web (prototipo)

Con el servidor corriendo, abre **http://127.0.0.1:8000/** e ingresa con cualquiera de los usuarios de la sección 3.5 (p. ej. `vendedor1`, `supervisor1` o `admin`; clave `Cambiar123!`).
Es una app web instalable (PWA) en `frontend/`, sin pasos de compilación: se edita `frontend/index.html` y se recarga.

| Rol | Menú que ve |
|---|---|
| Vendedor | Inicio · Ventas (nueva venta) · Clientes · Bodega |
| Supervisor | Inicio · Bodega (con calculadora de insumos por hectárea) · Terreno (registrar trabajo diario) |
| Administrador | Todo, más Finanzas (por cobrar y resumen del mes) y Nómina (calcular, aprobar y pagar) |

**Cómo funciona offline:** ventas, clientes nuevos y registros de terreno se guardan en el teléfono (`localStorage`) y se envían por lotes a
`/api/v1/sync/*/bulk/` cuando hay conexión (automático al reconectar, cada 60 s y con el botón 🔄). El catálogo se descarga al sincronizar.
Los registros con error se muestran en *Inicio* y se pueden descartar.

**Probarlo sin internet:** inicia sesión con conexión, abre las herramientas de desarrollo del navegador → *Network* → *Offline*, y crea una venta.
Verás “por enviar”. Al volver a *Online* se envía sola.

**Desde el celular:** `python manage.py runserver 0.0.0.0:8000` y abre `http://<IP-de-tu-PC>:8000/`. Instalar como app y abrir sin conexión
requiere **HTTPS** (o `localhost`); sin HTTPS funciona como página web normal con guardado local de datos.

**Limitaciones del prototipo:** el primer inicio de sesión necesita conexión; Finanzas y Nómina son solo en línea; no hay pantallas
para despachos ni abonos a deudas (la API sí los tiene); los datos locales no están cifrados.

## 5. Cómo funciona la sincronización offline

1. **UUID desde el cliente:** la app Android genera el `id` (UUID v4) de cada venta/desempeño/cliente. Reenviar el mismo lote **nunca duplica**.
2. **Subida masiva** (`POST /sync/ventas/bulk/`): hasta **500** registros por lote, como lista JSON o `{"ventas": [...]}`.
   Cada ítem se procesa en su propia transacción; uno inválido no bloquea a los demás. Respuesta:
   ```json
   {
     "resumen": {"recibidos": 3, "creados": 2, "duplicados": 0, "errores": 1},
     "resultados": [
       {"index": 0, "id": "…", "status": "created"},
       {"index": 1, "id": "…", "status": "duplicate"},
       {"index": 2, "id": "…", "status": "error", "errors": {"detalles": ["…"]}}
     ],
     "server_time": "2026-01-15T14:02:11Z"
   }
   ```
   HTTP `200` si todo salió bien, `207` si hubo algún error. La app marca como sincronizados los `created` y `duplicate`.
3. **Stock:** al sincronizar una venta se descuenta stock y se registra un `MovimientoStock`. Si el stock no alcanza, la venta **no se rechaza**
   (ya ocurrió físicamente): se descuenta lo disponible y queda `requiere_revision = true` para que el administrador la revise
   (`GET /ventas/?requiere_revision=true`).
4. **Descarga incremental:** `GET /sync/catalogo/?updated_since=<server_time anterior>` entrega clientes/productos (o trabajadores) modificados,
   **incluidos los borrados lógicos** (`is_deleted: true`). Guarda el `server_time` de la respuesta para la siguiente llamada.
   Si pasas la fecha en la URL, codifica el `+` del huso horario como `%2B`.
5. **Borrado lógico:** `DELETE` marca `is_deleted=true`; no elimina filas.

| Síntoma | Solución |
|---|---|
| `ModuleNotFoundError: No module named 'django'` | El entorno virtual no está activo o faltó `pip install -r requirements.txt`. |

| VS Code subraya imports en rojo | `Ctrl+Shift+P` → *Python: Select Interpreter* → elige `.venv`. |
| `401 Unauthorized` | Falta `Authorization: Bearer <token>` o el token venció (usa `auth/token/refresh/`). |
| `403` en un endpoint | El rol del usuario no tiene permiso (ver tabla de endpoints). |
| Puerto 8000 ocupado | `python manage.py runserver 8001`. |

import uuid

from django.db import models


class SyncModel(models.Model):
    """Base abstracta: PK UUID (generable offline) + campos para sincronización."""
    id = models.UUIDField(primary_key=True, default=uuid.uuid4, editable=False)
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True, db_index=True)  # pull incremental
    is_deleted = models.BooleanField(default=False, db_index=True)   # soft delete

    class Meta:
        abstract = True

from rest_framework.permissions import SAFE_METHODS, BasePermission

# Valores idénticos a users.models.Rol (se usan como strings para evitar imports circulares)
ADMIN = "ADMIN"
VENDEDOR = "VENDEDOR"
SUPERVISOR = "SUPERVISOR"


class HasRole(BasePermission):
    """
    RBAC declarativo. Cada vista define:
        read_roles  -> roles que pueden leer (GET/HEAD/OPTIONS). Si no existe, usa write_roles.
        write_roles -> roles que pueden escribir.
    El rol ADMIN (y los superusuarios) siempre tienen acceso.
    """
    message = "Tu rol no tiene permiso para esta operación."

    def has_permission(self, request, view):
        user = request.user
        if not (user and user.is_authenticated):
            return False
        if user.is_superuser or getattr(user, "rol", None) == ADMIN:
            return True
        write_roles = getattr(view, "write_roles", [])
        if request.method in SAFE_METHODS:
            roles = getattr(view, "read_roles", write_roles)
        else:
            roles = write_roles
        return user.rol in roles

from django.utils import timezone
from django.utils.dateparse import parse_datetime
from rest_framework.exceptions import ValidationError


def parse_updated_since(request):
    """Lee ?updated_since=<ISO8601>. Devuelve datetime aware o None."""
    raw = request.query_params.get("updated_since")
    if not raw:
        return None
    # En una URL el '+' del huso horario llega como espacio.
    dt = parse_datetime(raw.strip().replace(" ", "+"))
    if dt is None:
        raise ValidationError({"updated_since": "Formato inválido. Usa ISO 8601."})
    if timezone.is_naive(dt):
        dt = timezone.make_aware(dt)
    return dt

from django.core.exceptions import ValidationError


def normalizar_rut(value: str) -> str:
    """'12.345.678-5' -> '12345678-5'."""
    rut = str(value).replace(".", "").replace("-", "").replace(" ", "").upper()
    return f"{rut[:-1]}-{rut[-1]}" if len(rut) > 1 else rut


def validar_rut(value: str) -> None:
    rut = normalizar_rut(value)
    try:
        cuerpo, dv = rut.split("-")
    except ValueError:
        raise ValidationError("RUT inválido.")
    if not cuerpo.isdigit():
        raise ValidationError("RUT inválido.")
    suma, mult = 0, 2
    for d in reversed(cuerpo):
        suma += int(d) * mult
        mult = 2 if mult == 7 else mult + 1
    resto = 11 - (suma % 11)
    esperado = "0" if resto == 11 else "K" if resto == 10 else str(resto)
    if dv != esperado:
        raise ValidationError("RUT inválido (dígito verificador incorrecto).")

class SyncQuerysetMixin:
    """
    - Sin parámetros: devuelve solo registros no borrados.
    - Con ?updated_since=<ISO8601>: devuelve todo lo modificado desde esa fecha,
      INCLUYENDO borrados lógicos (is_deleted=true) para que el móvil los elimine.
    """
    permission_classes = [IsAuthenticated, HasRole]

    def get_queryset(self):
        qs = super().get_queryset()
        since = parse_updated_since(self.request)
        if since:
            return qs.filter(updated_at__gt=since)
        return qs.filter(is_deleted=False)

    def perform_destroy(self, instance):
        instance.is_deleted = True
        instance.save(update_fields=["is_deleted", "updated_at"])

class Remuneracion(SyncModel):
    class Estado(models.TextChoices):
        BORRADOR = "BORRADOR", "Borrador"
        APROBADA = "APROBADA", "Aprobada"
        PAGADA = "PAGADA", "Pagada"

    trabajador = models.ForeignKey("users.Trabajador", on_delete=models.PROTECT, related_name="remuneraciones")
    periodo_inicio = models.DateField()
    periodo_fin = models.DateField()
    total_produccion = models.DecimalField(max_digits=14, decimal_places=0, default=0)
    bonos = models.DecimalField(max_digits=12, decimal_places=0, default=0)
    descuentos = models.DecimalField(max_digits=12, decimal_places=0, default=0)
    total_liquido = models.DecimalField(max_digits=14, decimal_places=0, default=0)
    estado = models.CharField(max_length=10, choices=Estado.choices, default=Estado.BORRADOR)

    class Meta:
        ordering = ["-periodo_fin"]
        verbose_name_plural = "remuneraciones"
        constraints = [
            models.CheckConstraint(check=Q(periodo_fin__gte=F("periodo_inicio")),
                                   name="remuneracion_periodo_valido"),
        ]

    @transaction.atomic
    def calcular(self):
        """Suma los desempeños del periodo aún no liquidados y calcula el líquido."""
        pendientes = Desempeno.objects.filter(
            trabajador=self.trabajador,
            fecha__range=(self.periodo_inicio, self.periodo_fin),
            is_deleted=False,
        ).filter(Q(remuneracion__isnull=True) | Q(remuneracion=self))

        monto = ExpressionWrapper(F("cantidad") * F("tarifa_unitaria"),
                                  output_field=DecimalField(max_digits=16, decimal_places=2))
        total = pendientes.aggregate(t=Sum(monto))["t"] or Decimal("0")

        self.total_produccion = total.quantize(Decimal("1"))
        self.total_liquido = self.total_produccion + self.bonos - self.descuentos
        self.save()
        pendientes.update(remuneracion=self)   # evita pagar dos veces el mismo registro
        return self.total_liquido

    def __str__(self):
        return f"{self.trabajador.nombre} {self.periodo_inicio}→{self.periodo_fin}: ${self.total_liquido}"

from decimal import Decimal

from django.db import transaction

from .models import ItemBodega, MovimientoStock


class StockInsuficiente(Exception):
    pass


@transaction.atomic
def aplicar_movimiento(item_id, tipo, cantidad, usuario=None, motivo="",
                       referencia=None, permitir_faltante=False):
    """
    Único punto de entrada para modificar stock (bloquea la fila con SELECT ... FOR UPDATE).

    - ENTRADA: suma `cantidad`.
    - SALIDA : resta `cantidad`. Si no alcanza:
        * permitir_faltante=False -> lanza StockInsuficiente.
        * permitir_faltante=True  -> descuenta lo que haya (queda en 0) y devuelve el faltante.
          (Caso ventas offline: la venta ya ocurrió físicamente.)
    - AJUSTE : `cantidad` es el NUEVO stock total (conteo físico).
    Devuelve (movimiento, faltante).
    """
    item = ItemBodega.objects.select_for_update().get(pk=item_id)
    cantidad = Decimal(cantidad)
    faltante = Decimal("0")

    if tipo == MovimientoStock.Tipo.ENTRADA:
        nuevo = item.cantidad_disponible + cantidad
        registrado = cantidad
    elif tipo == MovimientoStock.Tipo.SALIDA:
        nuevo = item.cantidad_disponible - cantidad
        registrado = cantidad
        if nuevo < 0:
            if not permitir_faltante:
                raise StockInsuficiente(
                    f"Stock insuficiente de '{item.nombre}': hay {item.cantidad_disponible}, "
                    f"se pidió {cantidad}."
                )
            faltante = -nuevo
            registrado = item.cantidad_disponible
            nuevo = Decimal("0")
            motivo = (motivo + f" | FALTANTE {faltante}").strip(" |")
    elif tipo == MovimientoStock.Tipo.AJUSTE:
        if cantidad < 0:
            raise StockInsuficiente("El stock ajustado no puede ser negativo.")
        registrado = abs(cantidad - item.cantidad_disponible)
        nuevo = cantidad
    else:
        raise ValueError(f"Tipo de movimiento inválido: {tipo}")

    item.cantidad_disponible = nuevo
    item.save(update_fields=["cantidad_disponible", "updated_at"])
    mov = MovimientoStock.objects.create(
        item=item, tipo=tipo, cantidad=registrado, motivo=motivo[:200],
        referencia=referencia, usuario=usuario,
    )
    return mov, faltante

            "disponible": insumo.cantidad_disponible,
            "faltante": max(requerido - insumo.cantidad_disponible, Decimal("0")),

class Venta(SyncModel):
    class Estado(models.TextChoices):
        CONFIRMADA = "CONFIRMADA", "Confirmada"
        ANULADA = "ANULADA", "Anulada"

    cliente = models.ForeignKey("users.Cliente", on_delete=models.PROTECT, related_name="ventas")
    vendedor = models.ForeignKey("users.User", on_delete=models.PROTECT, related_name="ventas")
    fecha = models.DateTimeField()  # momento real de la venta (puede ser offline)
    estado = models.CharField(max_length=12, choices=Estado.choices, default=Estado.CONFIRMADA)
    total = models.DecimalField(max_digits=14, decimal_places=0, default=0)
    observaciones = models.TextField(blank=True)

    # Metadatos de sincronización offline
    device_id = models.CharField(max_length=64, blank=True)
    synced_at = models.DateTimeField(null=True, blank=True)
    requiere_revision = models.BooleanField(
        default=False, help_text="Ej: stock insuficiente al sincronizar una venta offline."
    )

    class Meta:
        ordering = ["-fecha"]
        indexes = [models.Index(fields=["cliente", "-fecha"])]

    def recalcular_total(self, save=True):
        self.total = self.detalles.aggregate(t=Sum("subtotal"))["t"] or Decimal("0")
        if save:
            self.save(update_fields=["total", "updated_at"])
        return self.total

    @property
    def total_pagado(self) -> Decimal:
        return self.pagos.filter(estado=Pago.Estado.PAGADO).aggregate(t=Sum("monto"))["t"] or Decimal("0")

    @property
    def saldo_pendiente(self) -> Decimal:
        return self.total - self.total_pagado

    @property
    def estado_pago(self) -> str:
        pagado = self.total_pagado
        if self.total > 0 and pagado >= self.total:
            return Pago.Estado.PAGADO
        return Pago.Estado.PARCIAL if pagado > 0 else Pago.Estado.PENDIENTE

    def __str__(self):
        return f"Venta {str(self.id)[:8]} - {self.cliente.nombre} - ${self.total}"

from django.db import transaction
from django.utils import timezone

from apps.inventory.models import MovimientoStock
from apps.inventory.services import aplicar_movimiento

from .models import DetalleVenta, Despacho, Pago, Venta


@transaction.atomic
def registrar_venta(validated_data):
    """
    Crea la venta con sus detalles, pagos y despacho, y descuenta el stock.
    Si el stock no alcanza NO se rechaza (la venta ya ocurrió en terreno):
    se descuenta lo disponible y se marca `requiere_revision=True`.
    """
    detalles = validated_data.pop("detalles")
    pagos = validated_data.pop("pagos", [])
    despacho = validated_data.pop("despacho", None)

    venta = Venta.objects.create(**validated_data)
    for d in detalles:
        DetalleVenta.objects.create(venta=venta, **d)
    for p in pagos:
        Pago.objects.create(venta=venta, **p)
    if despacho:
        Despacho.objects.create(venta=venta, **despacho)

    venta.recalcular_total(save=False)

    for d in venta.detalles.select_related("producto"):
        _, faltante = aplicar_movimiento(
            d.producto_id, MovimientoStock.Tipo.SALIDA, d.cantidad,
            usuario=venta.vendedor, motivo=f"Venta {str(venta.id)[:8]}",
            referencia=venta.id, permitir_faltante=True,
        )
        if faltante > 0:
            venta.requiere_revision = True

    venta.save(update_fields=["total", "requiere_revision", "updated_at"])
    return venta


@transaction.atomic
def anular_venta(venta, usuario):
    """Anula la venta, repone el stock y anula pagos pendientes."""
    if venta.estado == Venta.Estado.ANULADA:
        return venta
    for d in venta.detalles.all():
        aplicar_movimiento(
            d.producto_id, MovimientoStock.Tipo.ENTRADA, d.cantidad,
            usuario=usuario, motivo=f"Anulación venta {str(venta.id)[:8]}", referencia=venta.id,
        )
    venta.pagos.filter(estado=Pago.Estado.PENDIENTE).update(
        estado=Pago.Estado.ANULADO, updated_at=timezone.now())
    venta.estado = Venta.Estado.ANULADA
    venta.save(update_fields=["estado", "updated_at"])
    return venta

class CuentasPorCobrarView(_FinanzasView):
    """GET /finanzas/cuentas-por-cobrar/[?cliente=<uuid>] -> deuda agrupada por cliente."""

    def get(self, request):
        dinero = DecimalField(max_digits=16, decimal_places=0)
        pagado = Coalesce(
            Sum("pagos__monto", filter=Q(pagos__estado=Pago.Estado.PAGADO)),
            Value(0), output_field=dinero,
        )
        qs = (Venta.objects
              .filter(estado=Venta.Estado.CONFIRMADA, is_deleted=False)
              .annotate(pagado=pagado)
              .annotate(saldo=ExpressionWrapper(F("total") - F("pagado"), output_field=dinero))
              .filter(saldo__gt=0)
              .select_related("cliente"))
        cliente = request.query_params.get("cliente")
        if cliente:
            qs = qs.filter(cliente_id=cliente)

        por_cliente = defaultdict(lambda: {"deuda": Decimal("0"), "ventas": 0})
        for v in qs:
            fila = por_cliente[v.cliente_id]
            fila.update(cliente=str(v.cliente_id), nombre=v.cliente.nombre, rut=v.cliente.rut)
            fila["deuda"] += v.saldo
            fila["ventas"] += 1
        filas = sorted(por_cliente.values(), key=lambda f: f["deuda"], reverse=True)
        return Response({
            "total_por_cobrar": sum((f["deuda"] for f in filas), Decimal("0")),
            "clientes": filas,
        })


class RentabilidadView(_FinanzasView):
    """GET /finanzas/rentabilidad/?desde=YYYY-MM-DD&hasta=YYYY-MM-DD (por defecto: mes actual)."""

    def get(self, request):
        hoy = timezone.localdate()
        desde = parse_date(request.query_params.get("desde", "")) or hoy.replace(day=1)
        hasta = parse_date(request.query_params.get("hasta", "")) or hoy
        if hasta < desde:
            raise ValidationError({"hasta": "Debe ser posterior a 'desde'."})

        ventas = Venta.objects.filter(
            estado=Venta.Estado.CONFIRMADA, is_deleted=False,
            fecha__date__gte=desde, fecha__date__lte=hasta)
        total_ventas = ventas.aggregate(t=Sum("total"))["t"] or Decimal("0")
        cobrado = (Pago.objects.filter(venta__in=ventas, estado=Pago.Estado.PAGADO)
                   .aggregate(t=Sum("monto"))["t"] or Decimal("0"))
        nomina = (Remuneracion.objects
                  .filter(estado__in=[Remuneracion.Estado.APROBADA, Remuneracion.Estado.PAGADA],
                          periodo_fin__gte=desde, periodo_fin__lte=hasta, is_deleted=False)
                  .aggregate(t=Sum("total_liquido"))["t"] or Decimal("0"))
        por_categoria = list(
            DetalleVenta.objects.filter(venta__in=ventas)
            .values("producto__categoria").annotate(total=Sum("subtotal")).order_by("-total"))

        return Response({
            "desde": desde, "hasta": hasta,
            "ventas_totales": total_ventas,
            "cobrado": cobrado,
            "por_cobrar": total_ventas - cobrado,
            "costo_nomina": nomina,
            "margen_estimado": total_ventas - nomina,
            "ventas_por_categoria": [
                {"categoria": r["producto__categoria"], "total": r["total"]} for r in por_categoria],
            "nota": "Margen estimado = ventas - nómina aprobada/pagada. "
                    "Aún no incluye costo de insumos ni compras a proveedores.",
        })

MAX_LOTE = 500


def _a_uuid(valor):
    try:
        return uuid.UUID(str(valor))
    except (ValueError, AttributeError, TypeError):
        return None


class BulkUploadView(APIView):
    """
    Base para subida masiva offline.

    Entrada:  [ {...}, {...} ]   o   {"<clave>": [ {...}, ... ]}   (máx. 500 ítems)
    Reglas:
      * Cada ítem DEBE traer `id` (UUID generado en el dispositivo) -> idempotencia.
      * Cada ítem se procesa en su propia transacción: uno inválido no bloquea al resto.
      * Si el `id` ya existe en el servidor -> status "duplicate" (no se vuelve a crear).
    Respuesta: 200 si todo OK, 207 si hubo algún error.
    """
    permission_classes = [IsAuthenticated, HasRole]
    serializer_class = None
    model = None
    clave = "items"

    def get_save_kwargs(self, request):
        return {}

    def _extraer_items(self, data):
        if isinstance(data, list):
            return data
        if hasattr(data, "get"):
            items = data.get(self.clave)
            if isinstance(items, list):
                return items
        return None

    def post(self, request):
        items = self._extraer_items(request.data)
        if items is None:
            return Response(
                {"detail": f"Envía una lista JSON o un objeto con la clave '{self.clave}'."},
                status=status.HTTP_400_BAD_REQUEST)
        if len(items) > MAX_LOTE:
            return Response({"detail": f"Máximo {MAX_LOTE} registros por lote."},
                            status=status.HTTP_400_BAD_REQUEST)

        ids = {_a_uuid(i.get("id")) for i in items if isinstance(i, dict)} - {None}
        existentes = set(self.model.objects.filter(pk__in=ids).values_list("pk", flat=True))
        save_kwargs = self.get_save_kwargs(request)

        resultados, conteo = [], {"created": 0, "duplicate": 0, "error": 0}
        for idx, item in enumerate(items):
            res = {"index": idx, "id": None, "status": "error"}
            if not isinstance(item, dict):
                res["errors"] = {"detail": "Cada registro debe ser un objeto JSON."}
            elif (item_id := _a_uuid(item.get("id"))) is None:
                res["errors"] = {"id": "Requerido: UUID generado en el dispositivo."}
            else:
                res["id"] = str(item_id)
                if item_id in existentes:
                    res["status"] = "duplicate"
                else:
                    ser = self.serializer_class(data=item, context={"request": request})
                    if ser.is_valid():
                        try:
                            with transaction.atomic():
                                ser.save(**save_kwargs)
                            res["status"] = "created"
                            existentes.add(item_id)   # duplicados dentro del mismo lote
                        except Exception as exc:  # noqa: BLE001
                            logger.exception("Error guardando registro offline %s", item_id)
                            res["errors"] = {"detail": str(exc)}
                    else:
                        res["errors"] = ser.errors
            conteo[res["status"]] += 1
            resultados.append(res)

        http = status.HTTP_200_OK if conteo["error"] == 0 else status.HTTP_207_MULTI_STATUS
        return Response({
            "resumen": {"recibidos": len(items), "creados": conteo["created"],
                        "duplicados": conteo["duplicate"], "errores": conteo["error"]},
            "resultados": resultados,
            "server_time": timezone.now(),
        }, status=http)

class CatalogoView(APIView):
    """
    Descarga de catálogo para trabajar offline, SIN paginación, en una sola llamada.
    GET /sync/catalogo/?updated_since=<ISO8601>
    Guarda `server_time` y úsalo como `updated_since` en la próxima sincronización.
    Incluye borrados lógicos (is_deleted=true) cuando se usa updated_since.
    """
    permission_classes = [IsAuthenticated]

    def get(self, request):
        since = parse_updated_since(request)
        rol = request.user.rol
        es_admin = request.user.is_superuser or rol == ADMIN

        def filtrar(qs):
            return qs.filter(updated_at__gt=since) if since else qs.filter(is_deleted=False)

        data = {"server_time": timezone.now()}
        if es_admin or rol == VENDEDOR:
            data["clientes"] = ClienteSerializer(filtrar(Cliente.objects.all()), many=True).data
            data["productos"] = ProductoVentaSerializer(
                filtrar(ProductoVenta.objects.all()), many=True).data
        if es_admin or rol == SUPERVISOR:
            data["trabajadores"] = TrabajadorSerializer(
                filtrar(Trabajador.objects.all()), many=True).data
        return Response(data)

        model = User
        fields = ["id", "username", "first_name", "last_name", "email",
                  "rol", "persona", "is_active", "password"]

    def create(self, validated_data):
        password = validated_data.pop("password", None)
        user = User(**validated_data)
        if password:
            user.set_password(password)
        else:
            user.set_unusable_password()
        user.save()
        return user

    def update(self, instance, validated_data):
        password = validated_data.pop("password", None)
        for attr, value in validated_data.items():
            setattr(instance, attr, value)
        if password:
            instance.set_password(password)
        instance.save()
        return instance

def _dv(cuerpo: int) -> str:
    """Dígito verificador de un RUT chileno (módulo 11)."""
    suma, mult = 0, 2
    for d in reversed(str(cuerpo)):
        suma += int(d) * mult
        mult = 2 if mult == 7 else mult + 1
    resto = 11 - (suma % 11)
    return "0" if resto == 11 else "K" if resto == 10 else str(resto)


def rut(cuerpo: int) -> str:
    return f"{cuerpo}-{_dv(cuerpo)}"
